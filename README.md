# Expense Manager

An expense-management application that helps users record and categorize their income and expenses, giving them a clearer view of their personal finances.

## Tech Stack

- Frontend: React, TypeScript, and Vite
- API: Hono and Node.js
- Project structure: monorepo managed with npm workspaces

## Getting Started

Install the dependencies from the project root:

```bash
npm install
```

Start the frontend:

```bash
npm run dev:web
```

Start the API in a separate terminal:

```bash
npm run dev:api
```

Vite displays the frontend URL in the terminal. By default, the API is available at `http://localhost:3000`.
